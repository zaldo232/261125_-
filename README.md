자기소개에는 황성호·260199, 인사말 타이핑, 관심 분야 카드 펼치기, 목표 체크리스트와 Top 5를 구성했습니다. 다크모드·목표 체크는 새로고침 후 유지됩니다. 관심 분야와 목표·좋아하는 것은 실습 예시이며 이메일은 등록 예정입니다.

기본 실습 단일 HTML 재생성: `node tools/build-base-standalone.cjs`.

## 추가 실습 2-A · 공학용 계산기

외부 라이브러리와 CDN 없이 HTML, CSS, JavaScript로 구현한 공학용 계산기입니다.

### 바로 실행

저장소 맨 위의 **index.html**을 브라우저에서 열면 됩니다. 이 파일에는 CSS와 JavaScript가 포함되어 있어 파일 하나만 복사해도 실행됩니다. 설치, 인터넷 연결, 서버 실행이 필요하지 않습니다.

분리된 원본은 `calculator/index.html`, `calculator/style.css`, `calculator/app.js`입니다.

### 지원 기능

- 사칙연산, 괄호, 제곱과 거듭제곱, 제곱근, 백분율
- 연산 우선순위 적용 및 오른쪽부터 계산하는 거듭제곱
- 키보드 입력, Enter 계산, Esc 초기화, Backspace 삭제
- 결과에 연산자를 이어 계산하거나 새 숫자로 새 계산 시작
- 최근 계산 5개 표시, 기록 다시 불러오기와 지우기
- 휴대폰 화면에 맞춰 바뀌는 배치와 키보드 접근성

| 입력 | 결과 |
| --- | --- |
| `2*(3+4)^2` | `98` |
| `sqrt(81)` | `9` |
| `2^3^2` | `512` |
| `-2^2` | `-4` |
| `(-2)^2` | `4` |
| `200*10%` | `20` |
| `0.1+0.2` | `0.3` |

제곱근은 `sqrt(9)` 또는 `√(9)`로 입력합니다. `2(3+4)`처럼 곱셈을 생략하지 않고 `2*(3+4)`로 입력합니다. `%`는 해당 수를 100으로 나누는 연산입니다.

### 구현과 검증

`eval()`과 `Function()`을 사용하지 않고 수식을 토큰으로 나눈 뒤 재귀 하강 파서로 계산합니다. 0으로 나누기, 음수의 제곱근, 잘못된 괄호, 과도한 길이와 계산 범위 초과는 안내 문구로 처리합니다.

Node.js가 설치된 환경에서 테스트를 실행할 수 있습니다. 앱 실행에는 Node.js가 필요하지 않습니다.

```powershell
node --test calculator/calculator.test.cjs
```

자동 테스트 50개가 통과했습니다. 브라우저에서 예제의 결과 98, 키보드 계산, 제곱 버튼, 오류 표시, 최근 기록과 320px 모바일 화면을 확인했습니다. 구체적인 결과는 [검증 기록](VERIFICATION.md)에 있습니다.

단일 HTML을 다시 만들려면 다음 명령을 실행합니다.

```powershell
node tools/build-standalone.cjs
```

JavaScript의 일반 숫자 연산을 사용하며 표시 결과는 유효숫자 12자리로 정리합니다. 최근 기록은 현재 페이지가 열려 있는 동안만 유지됩니다.
